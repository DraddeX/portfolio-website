    ASP.NET MVC Webapplicatie

    Een full-stack webapplicatie gebouwd met ASP.NET Core MVC. Bevat gebruikersauthenticatie met JWT, een winkelwagen, productbeheer en volledige database-integratie via Entity Framework Core.

    Wat ik heb gebouwd

    Dit project is een complete webshop, volledig zelf gebouwd met het MVC-patroon. Gebruikers kunnen registreren, inloggen, producten bekijken, items aan een winkelwagen toevoegen en bestellingen plaatsen. Een adminpaneel maakt product- en orderbeheer mogelijk.

    Wat ik heb geleerd

    • JWT-gebaseerde authenticatie en autorisatie implementeren
    • Werken met Entity Framework Core migrations en relaties
    • Een project structureren met het MVC-patroon
    • RESTful API-endpoints bouwen die door de frontend worden gebruikt
