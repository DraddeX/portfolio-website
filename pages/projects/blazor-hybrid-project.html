    Blazor Hybrid Ride-Sharing App

    A real-time ride-sharing application built with .NET Blazor Hybrid. Users can request and offer rides, track status live via SignalR, and manage their profile — all from a component-based architecture that runs on both web and desktop.

    .NET Blazor Hybrid C# SignalR Entity Framework Core SQL Server

    Screenshots

    What I built

    A full ride-sharing platform where drivers can post available rides and passengers can book them. Real-time updates are pushed to all connected clients using SignalR so ride status changes are instant. The app shares code between web and native targets through Blazor Hybrid.

    What I learned

    • Setting up and using SignalR hubs for real-time communication
    • Building reusable Blazor components across web and desktop
    • Managing state in a component-based UI architecture
    • Designing relational data models with EF Core

    Tech stack

    • Framework: .NET Blazor Hybrid
    • Real-time: SignalR
    • Database: SQL Server, Entity Framework Core
    • Language: C#
    • Tools: Visual Studio, GitHub
