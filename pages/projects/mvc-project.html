    ASP.NET MVC Web Application

    A full-stack web application built with ASP.NET Core MVC. Features user authentication with JWT, a shopping cart, product management, and full database integration via Entity Framework Core.

    ASP.NET Core C# Entity Framework JWT Auth SQL Server MVC

    What I built

    This project is a complete web shop built from scratch using the MVC pattern. Users can register, log in, browse products, add items to a cart, and place orders. An admin panel allows product and order management.

    What I learned

    • Implementing JWT-based authentication and authorization
    • Working with Entity Framework Core migrations and relationships
    • Structuring a project using the MVC pattern
    • Building RESTful API endpoints consumed by the frontend

    Tech stack

    • Backend: ASP.NET Core, C#, Entity Framework Core
    • Auth: JWT Bearer tokens
    • Database: SQL Server
    • Frontend: Razor Views, Bootstrap
    • Tools: Visual Studio, GitHub
